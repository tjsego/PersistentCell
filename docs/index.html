A standard, single-cell CPM with only area and perimeter terms (diffusive motion without persistence).

With: $$H = H_\text{area} + H_\text{perimeter}$$ $$H_\text{area} = \lambda_\text{area} (A(t) - A_\text{target})^2$$ $$H_\text{perimeter} = \lambda_\text{perim} (P(t) - P_\text{target})^2$$ with $A(t)$ and $P(t)$ the cell's current area and perimeter, respectively.

MODEL003

Extends MODEL000 with a term to favour motion in a static target direction (yielding ballistic motion).

Where we extend model000 with a work term: $$\Delta H_\text{dir} = \lambda_\text{dir} (\vec{e_\alpha} \cdot \vec{a})$$ where $\vec{e_\alpha}= ( \cos \alpha, \sin \alpha )$ is a unit vector in a (fixed) reference direction $\alpha$ and $\vec{a}$ is the (unnormalized) vector pointing from source to target pixel involved in the copy attempt.

MODEL005

Similar to MODEL003, but target directions can adapt through self-reinforcement of random fluctuations.

Rephrasing the target direction in model003 $$\Delta H_\text{dir} = \lambda_\text{dir} (\tfrac{\vec{u}(t)}{||\vec{u}(t)||} \cdot \vec{a})$$ $$\vec{u}(t)= P_\text{persist}\vec{u}(t-1) + (1-P_\text{persist})\vec{\Delta c} (\Delta t)$$ where $\vec{a}$ is defined as in model003 and $\vec{\Delta c}(\Delta t)$ is the (normalized) observed displacement vector of the cell centroid over the last $\Delta t$ MCS, and $\Delta t$ determines persistence time.
